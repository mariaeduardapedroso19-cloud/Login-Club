# Login-Club 🔐

Sistema de login seguro em PHP e MySQL, desenvolvido como projeto de portfólio.

### 🚀 Tecnologias
- PHP 8
- MySQL
- HTML5 / CSS3
- Segurança com Prepared Statements e password_hash

### ✨ Funcionalidades
- [x] Cadastro de usuário com senha criptografada
- [x] Login com verificação segura
- [x] Proteção contra SQL Injection
